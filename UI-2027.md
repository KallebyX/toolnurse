# ToolNurse — interface 2027

Atualização visual dos nove formulários de puericultura. Preserva campos, opções, condições, estados e a geração do texto de `Copiar Dados`.

## Interface

- Navegação por faixa etária em barra lateral, com menu expansível no celular.
- Formulários responsivos, tipografia Lato local e controles com foco visível.
- Labels clicáveis para opções antes sem associação.
- Rodapé com crédito à Oryum Tech e Universidade Franciscana.
- A página inicial abre o roteiro de Recém-nascido; `/recem` continua disponível.
- Guia em `/como-utilizar` e apresentação do projeto em `/sobre`, acessíveis pelo menu e pelo rodapé.

## Identificação nos buscadores

Os títulos, descrições e endereços canônicos ficam em `src/seo/pages.json`. O build gera HTML com metadados próprios para cada rota e um `sitemap.xml`; `robots.txt` informa o endereço do mapa. A navegação interna atualiza os mesmos metadados. `/` e `/recem` apontam para a página canônica `/` para evitar duplicação do roteiro inicial.

O nome ToolNurse também consta nos metadados sociais e nos dados estruturados `WebSite`. Buscadores podem continuar exibindo o título antigo até rastrear novamente o domínio; uma nova indexação depende do buscador.


O contrato em `tests/clinical-contract.json` foi gerado do código anterior (commit `c222276`) e verifica os estados, handlers, dados dos controles, condições, opções mapeadas e rotas. Em 25/11/2026, somente a lista de rotas foi atualizada para refletir a página inicial Recém-nascido e as duas páginas informativas solicitadas. Os contratos dos nove formulários continuam idênticos. Altere a referência apenas quando uma mudança funcional for expressamente autorizada. O lockfile foi alinhado às versões já declaradas no package.json.

## Publicação estática

A aplicação continua estática. Publique todo o conteúdo de `dist/`, incluindo os diretórios das rotas. A configuração Nginx em `deploy/nginx.conf` serve primeiro os arquivos de cada rota e mantém o fallback para `index.html`. Envie os assets primeiro e substitua o HTML por último. Preserve os assets da versão anterior durante a transição para não interromper sessões abertas.

Endereço oficial: https://toolnurse.ufn.edu.br. A TI da UFN configurou esse domínio para encaminhar à aplicação no Portainer (stack `toolnurse-preview`, porta interna de publicação `32779`). O nome da stack foi mantido para preservar o apontamento.

O endereço `toolnurse-preview.app.ufn.edu.br` funciona como redirecionamento permanente para o domínio oficial, preservando caminhos e parâmetros. A configuração mantém a validação de certificados da entrada antiga. O backup anterior enviado pela TI foi preservado antes da conclusão da migração.
