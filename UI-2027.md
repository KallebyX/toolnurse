# ToolNurse — interface 2027

Atualização visual dos nove formulários de puericultura. Preserva rotas, campos, opções, condições, estados e a geração do texto de `Copiar Dados`.

## Interface

- Navegação por faixa etária em barra lateral, com menu expansível no celular.
- Formulários responsivos, tipografia Lato local e controles com foco visível.
- Labels clicáveis para opções antes sem associação.
- Rodapé com crédito à Oryum Tech e Universidade Franciscana.

## Verificação

```sh
npm ci
npm run verify:preservation
npm run build
```

O contrato em `tests/clinical-contract.json` foi gerado do código anterior (commit `c222276`) e verifica os estados, handlers, dados dos controles, condições, opções mapeadas e rotas. Altere a referência apenas quando uma mudança funcional for expressamente autorizada. O lockfile foi alinhado às versões já declaradas no package.json.

## Publicação estática

A aplicação continua estática, com as mesmas rotas. Publique o conteúdo de `dist/` no diretório web atual, mantendo o fallback de rotas para `index.html`. Envie os assets primeiro e substitua `index.html` por último. Preserve os assets da versão anterior durante a transição para não interromper sessões abertas.

Endereço atual: https://toolnurse.ufn.edu.br. Esta hospedagem é separada do servidor Portainer utilizado por Aproxima/Aninhar.
